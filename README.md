# Eleftheria Website

Public marketing site for Eleftheria.

## Deploy on Vercel

1. Import this repository in the Vercel dashboard.
2. Framework Preset: **Other** (static).
3. Build Command: leave empty.
4. Output Directory: leave empty / `.` (root).
5. Deploy.

The waitlist form posts to `/api/waitlist`. Wire that endpoint separately (backend or a serverless function) if you need signups to work.
